# GLOBAL\_PLANCACHE\_CLEAN<a name="EN-US_TOPIC_0297927202"></a>

**GLOBAL\_PLANCACHE\_CLEAN**  clears the global plan cache that is not used on all nodes. The return value is of the Boolean type.
