# GMS_INADDR Package

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-09-06T11:14:12.493Z pushedAt=2026-09-22T11:12:32.640Z -->

## Availability

This feature has been available since openGauss 7.0.0-RC1.

## Feature Overview

This feature implements the [GMS_INADDR Package](../extension_reference/gms_inaddr.md), providing multiple IP address and host name conversion-related function interfaces for users.

## Customer Benefits

GMS_INADDR helps users switch between host names and IP addresses.

## Feature Description

- Through the `GMS_INADDR` advanced package, specify an IP address or a host name to obtain the corresponding host name and IP address.

## Feature Enhancements

None.

## Feature Constraints

- The plug-in can be loaded only by using the CREATE EXTENSION command.

## Dependencies

None.
