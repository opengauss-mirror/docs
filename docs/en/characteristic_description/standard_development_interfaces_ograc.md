# Support for the ograc Standard Development Interface

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-09-06T11:32:44.818Z pushedAt=2026-09-22T11:12:32.711Z -->

## Availability<a name="section663215"></a>

This feature has been available since ograc 1.0.0.

## Feature Overview<a name="section5968939"></a>

Supports the ODBC and JDBC standard interfaces.

## Customer Benefits<a name="section53720453"></a>

Provides industry-standard ODBC and JDBC interfaces, ensuring that user applications can interact with the ograc database and enhancing application portability, scalability, and maintainability.

## Feature Description<a name="section13722030"></a>

Currently, standard ODBC and JDBC interfaces are supported. ODBC supports the Win32 and Win64 platforms, while JDBC has no platform differences.

## Feature Enhancements<a name="section56389407"></a>

None.

## Feature Constraints<a name="section06531946143616"></a>

None.

## Dependencies<a name="section37742617"></a>

ODBC depends on unixODBC. Install unixODBC before using ODBC. The use of JDBC depends on the JDK environment. Install the JDK first.
