## Background<a name="section1195011494620"></a>

DBMind is an intelligent O&M platform launched by the openGauss database, dedicated to providing users with automated O&M services throughout the full lifecycle of the database. Based on AI and machine learning technologies, it monitors the database running status in real time, automatically identifies and diagnoses performance bottlenecks, and provides optimization suggestions, helping users reduce O&M costs and improve database performance and stability.

## Usage Scenarios<a name="section174241635124617"></a>

The current usage scenarios of DBMind mainly include the following three aspects:

- Anomaly detection: Monitors key metrics in real time and detects anomalies in a timely manner.
- Risk analysis: Provides time-series forecasting to detect unknown risks in advance and prevent faults from escalating.
- Performance optimization: Provides index recommendation to suggest indexes for slow SQL statements, improving SQL performance.
