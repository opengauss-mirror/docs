# pg_xlogdump

## Background<a name="zh-cn_topic_0237152442_section125419154814"></a>

`pg_xlogdump` is a tool used to decode and display openGauss Write-Ahead Logging (WAL) records. This tool can only be used by the user who installed the server, as it requires read-only access to the data directory.

>[!WARNING] Warning
>
>Decoding segment-page files is not supported yet.<br/>

## Prerequisites<a name="zh-cn_topic_0237152442_section14602518110"></a>

Ensure that the database directory exists and the path is correct.

## Syntax<a name="zh-cn_topic_0237152442_section554725769"></a>

```
pg_xlogdump [OPTION]... [STARTSEG [ENDSEG]]
```

## Parameter Description<a name="zh-cn_topic_0237152442_section4751333172416"></a>

`OPTION` takes the following values:

- -b, --bkp-details

    Output detailed information about backup blocks.

- -e, --end=RECPTR

    Stop reading at the specified log position.

- -f, --follow

    After reaching the end of the specified WAL, continue parsing the next file.

- -n, --limit=N

    Specify the number of log records to display.

- -p, --path=PATH

    Specify the directory where WAL logs are stored. The default path is `./pg_xlog`.

- -r, --rmgr=RMGR

    Only display records generated by the specified resource manager. If the parameter is set to `-r = list`, valid resource manager names will be listed.

- -s, --start=RECPTR

    Specify the starting position for reading log records. By default, reading starts from the first available log record of the earliest file found.

- -S, --size=n

    Set the size when parsing logs in resource pooling mode (excluding the ctl information length).
    The default size is 512*1024*1024*1024 (512 GB).

- -t, --timeline=TLI

    Select the specified timeline to read log records. Defaults to `1` or `STARTSEG`.

- -V, --version

    Display version information.

- -w, --write-FPW

    Display full-page write information. This option should be used together with `-b`.

- -x XID

    Only display records for the given transaction ID.

- -z, --stats

    Display statistics of inserted records instead of displaying each record.

- -v, --verbose

    Output detailed information for each record.

- -?, --help

    Print help information.

- --enable-dss

    Resource pooling parameter. Enables resource pooling mode.

- --socketpath=SOCKETPATH

    Resource pooling parameter. The socket file path used by the dss instance process.

## Example<a name="zh-cn_topic_0237152442_section554725770"></a>

+ Parse the xlog file for a given transaction ID.

```
pg_xlogdump -x [XID] [start log position]
```
