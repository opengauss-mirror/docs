# openGauss-server Compilation Failed

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-29T02:42:22.846Z pushedAt=2026-07-29T09:36:05.608Z -->

## Symptom

The openGauss-server compilation failed, reporting: "configure failed". 

## Cause

The third-party libraries or GCC version is not compatible.

## Solution

Check the existing system and GCC version information, and download the corresponding version of third-party libraries.
