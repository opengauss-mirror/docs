Modifying CM-related parameters affects the operating mechanism of openGauss. It is recommended that the modification be assisted by an openGauss engineer. For the method of modifying CM-related parameters, see [CM Configuration Parameters Introduction](../tool_and_commandreference/cm_parameters.md).
