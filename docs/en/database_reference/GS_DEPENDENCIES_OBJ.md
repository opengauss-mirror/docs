# GS\_DEPENDENCIES\_OBJ

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-09-03T11:41:25.252Z -->

The GS\_DEPENDENCIES\_OBJ system table records information about objects referenced by stored procedures, packages, or types. The information allows recording referenced objects that are not yet defined, and the recorded object information in the table is modified when a referenced object is created, altered, or dropped. To record referenced object information in the GS\_DEPENDENCIES\_OBJ system table, the GUC parameter `behavior\_compat\_options='plpgsql\_dependency'` must be set.
