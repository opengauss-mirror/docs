# GAUSS-53700 -- GAUSS-53799

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-09-03T11:40:01.201Z -->

GAUSS-53700: "This patch has been loaded before!."

SQLSTATE: None

Error cause: The hot patch has already been loaded.

Solution: This error generally occurs when a hot patch is loaded repeatedly, indicating that the hot patch does not need to be loaded again and no action is required.

GAUSS-53701: "This patch has not been loaded!."

SQLSTATE: None

Error cause: The hot patch has not been loaded yet.

Solution: This error generally occurs when activating a hot patch that has not been loaded. Load the hot patch first, and then execute the current operation again.

GAUSS-53702: "Status check failed, can not XXX"

SQLSTATE: None

Error cause: The operation to be performed does not comply with the state transition rules of the hot patch.

Solution: The state transition rules of the hot patch are load -\> activate -\> deactivate -\> unload. Execute the command according to the state transition rules.

GAUSS-53703: "Patch status file has been broken."

SQLSTATE: None

Error cause: The patch status file is damaged.

Solution: Copy a status file from an undamaged node to the damaged node.

GAUSS-53704: "Unzip om patch failed"

SQLSTATE: None

Error cause: Failed to decompress the hot patch file.

Solution: Check whether the hot patch file in use is damaged.

GAUSS-53705: "The XXX does not exist."

SQLSTATE: None

Error cause: The XXX file required in the patch process does not exist or is damaged.

Solution: Reload the patch.

GAUSS-53706: "Check patch SHA256SUM failed."

SQLSTATE: None

Error cause: The sha256sum verification failed.

Solution: Check whether the patch matches the version. This error generally occurs when the patch does not match the version.

GAUSS-53707: "Recover om hotpatch failed."

SQLSTATE: None

Error cause: The hot patch file is corrupted.

Solution: Reload and activate the corrupted hot patch.

GAUSS-53708: "Check base version failed."

SQLSTATE: None

Error cause: The baseline version of the hot patch does not match the current version.

Solution: Check whether the wrong patch was used, and use a hot patch that matches the version.

GAUSS-53709: "Create patch lock failed, other om process is running."

SQLSTATE: None

Error cause: When a hot patch operation is being executed, another om operation that is mutually exclusive with the hot patch is running.

Solution: Wait until the mutually exclusive om operation is complete, and then perform the hot patch operation.

GAUSS-53710: "Unzip server package failed."

SQLSTATE: None

Error cause: Failed to unzip the collection hot patch.

Solution: Check whether the collection hot patch is damaged and whether it can be unzipped separately.

GAUSS-53711: "Server package patch file is invalid."

SQLSTATE: None

Error cause: The collection hot patch is unavailable.

Solution: Check whether the collection hot patch file is damaged and whether it can be unzipped separately.
