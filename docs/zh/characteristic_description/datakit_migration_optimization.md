# Datakit迁移优化

## 可获得性

本特性自 openGauss 7.0.0 版本开始引入。

## 特性简介

Datakit 迁移优化特性围绕数据迁移全流程进行增强，通过自动创建`definer`用户、跳过全量校验及工具卸载一体化，提升迁移易用性、效率与可控性，满足不同场景下的迁移需求。

## 客户价值

Datakit 迁移优化特性从用户实际使用需求出发，为不同场景下的 Datakit 使用和迁移工作带来多方面价值：

- 对于 MySQL 迁移场景，特性降低了 MySQL 迁移对象操作的复杂度，提升了 MySQL 对象迁移成功率，提升了迁移工具的易用性和迁移效率。
- 对于迁移流程控制，特性实现后，用户可以根据业务需要选择是否启动全量校验进程，增加了用户对迁移流程的掌控能力。对于不需要数据校验的迁移场景，可以有效提升迁移效率。
- 对于 Datakit 卸载场景，特性实现了 Datakit 的一键卸载功能，用户可以通过统一入口完成 Datakit 自身及其安装的`migration-portal`、`prometheus`、`instance-exporter`工具的卸载，降低了 Datakit 和已安装工具的卸载复杂度，避免了卸载残留问题，提升了卸载效率。

## 特性描述

特性聚焦 Datakit 数据迁移功能，实现了以下功能：

- 在 MySQL 全量迁移流程中，当目标端连接用户具备 sysadmin 权限时，迁移工具会自动在目标端创建与 MySQL 对象 `definer` 同名的用户并完成权限赋值，无需用户手动干预用户创建与授权环节。
- 在 Datakit 迁移模式中新增不包含全量校验的模式选项，用户可根据业务需求选择是否启动校验进程。对于无需数据校验的场景，可跳过校验步骤以提升迁移效率。
- 新增 Datakit 卸载功能，支持通过选项控制卸载范围，可选择仅卸载 Datakit 自身，或同步卸载已安装的 `migration-portal`、`prometheus`、`instance-exporter` 工具，实现迁移相关组件的一键清理，避免卸载残留。

## 特性约束

使用Datakit卸载功能时，需要注意以下约束：

- 卸载远程环境上已安装的工具时，需要用户交互式输入安装环境的用户密码，用于连接远程主机执行卸载命令。
- 卸载远程环境上已安装的工具时，Datakit 所在环境需要提前安装 `sshpass` 命令，用于连接远程主机时传输用户密码。
