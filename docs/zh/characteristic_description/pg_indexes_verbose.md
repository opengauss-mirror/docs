# 冗余索引辅助诊断

## 可获得性<a name="section56086982"></a>

本特性自openGauss 7.0.0-RC3 版本开始引入。

## 特性简介

通过[冗余索引视图](../sql_reference/pg_indexes_verbose.md)，辅助诊断当前数据库中存在的潜在冗余索引。

## 客户价值<a name="section46751668"></a>

用户在使用数据库过程中，可能会产生一些无法被查询命中的索引，这些索引会影响数据写入性能。通过冗余索引视图，用户可以排查当前库中不再需要的索引。

## 特性描述<a name="section18111828"></a>

冗余索引视图提供了索引的命中次数，以及可覆盖当前索引列的索引信息。用户可按模式、表名、索引名进行查询，并根据这些信息判断索引是否冗余。

## 特性增强<a name="section28788730"></a>

无。

## 特性约束<a name="section06531946143616"></a>

无。

## 依赖关系<a name="section57771982"></a>
