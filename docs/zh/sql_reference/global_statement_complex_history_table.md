# GLOBAL\_STATEMENT\_COMPLEX\_HISTORY\_TABLE

显示各个节点执行作业结束后的负载管理记录。此数据是从内核中转储到系统表中的数据。具体的字段请参考[GLOBAL\_STATEMENT\_COMPLEX\_HISTORY](global_statement_complex_history.md)中的字段。
