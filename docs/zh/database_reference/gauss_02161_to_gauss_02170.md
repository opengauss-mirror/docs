# GAUSS-02161 -- GAUSS-02170

GAUSS-02161: "PGXC Node %s: cannot drop local node"

SQLSTATE: 42601

错误原因：语法错误，无法drop当前节点。

解决办法：禁止删除本地节点信息。

GAUSS-02167: "Can not connect to pool manager"

SQLSTATE: 58030

错误原因：系统内部错误。

解决办法：请联系技术支持工程师提供技术支持。
