# GAUSS-50700 -- GAUSS-50799

GAUSS-50700: "The firewall should be disabled."

SQLSTATE: 无

错误原因：防火墙没有关闭。

解决办法：关闭防火墙。

GAUSS-50701: "The firewall should be opened."

SQLSTATE: 无

错误原因：防火墙没有开启。

解决办法：开启防火墙。
