# GAUSS-04061 -- GAUSS-04070

GAUSS-04061: "could not load the ca certificate file"

SQLSTATE: XX000

错误原因：系统内部错误。

解决办法：请联系技术支持工程师提供技术支持。

GAUSS-04070: "spin.c does not support S\_LOCK\_FREE\(\)"

解决办法：检查操作系统是否在支持的范围内。
