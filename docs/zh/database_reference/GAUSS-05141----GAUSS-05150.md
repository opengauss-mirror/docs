# GAUSS-05141 -- GAUSS-05150

GAUSS-05145: "cannot drop '%s' because other objects depend on it"

SQLSTATE: 2BP01

错误原因： 系统内部错误。

解决办法：请联系技术支持工程师提供技术支持。

GAUSS-05150: "cannot drop '%s' because at least one role %u depend on it"

SQLSTATE: 2BP01

错误原因： 系统内部错误。

解决办法：请联系技术支持工程师提供技术支持。
