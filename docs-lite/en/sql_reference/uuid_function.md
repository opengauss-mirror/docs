# UUID Functions<a name="EN-US_TOPIC_0289899864"></a>

## UUID Functions

- gen\_random\_uuid\(\)

    Description: Generate a random version 4 uuid.

    Return type: uuid

    Example:

    ```sql
    openGauss=# select gen_random_uuid();
               gen_random_uuid            
    --------------------------------------
     a81069af-f9bd-4008-848f-d0350a758a22
    (1 row)
    ```
